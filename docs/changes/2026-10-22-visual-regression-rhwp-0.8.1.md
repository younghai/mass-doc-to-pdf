# rhwp 0.8.1 시각 회귀 검증 (품질 코퍼스 PNG 비교)

2026-10-22. rhwp-python 0.8.0(코어 0.7.16) → 0.8.1(코어 0.7.17) 범프의 후속
검증(`2026-10-18-rhwp-0.8.1-upgrade.md` "후속" 항목)으로, 텍스트·페이지 수
동일성에 이어 **렌더 픽셀 수준 비교**를 수행했다.

## 방법

- 대상: 품질 코퍼스 unique 4종 + 로컬 스모크 2종(HWP 3 · HWPX 2 · 총 40페이지).
  OPEN-001 문서는 양 버전에서 변환 실패라 제외.
- 0.8.0 / 0.8.1 venv에서 각각 `rhwp_worker.py`로 PDF 생성 → `pdftoppm`
  100 DPI PNG 래스터화 → Pillow 픽셀 diff(채널 델타 ≥ 8 기준).

## 결과

| 문서 | 페이지 | 결과 |
|---|---|---|
| 사업계획서.hwp | 14p | **전 페이지 픽셀 완전 일치** |
| localhost-smoke.hwp | 14p | **전 페이지 픽셀 완전 일치** |
| 사업계획서.hwpx | 2p | **전 페이지 픽셀 완전 일치** |
| localhost-smoke.hwpx | 2p | **전 페이지 픽셀 완전 일치** |
| 회의록류.hwp(7p) | 7p | 5p 일치, 2p 미세 변동(0.13% / 0.81%) |
| 감면신청서류.hwp(1p) | 1p | 10.7% — 줄바꿈 재배치 |

- **37/40 페이지 픽셀 동일**. 차이 3페이지 모두 텍스트 레이어 비교에서 이미
  변경이 확인됐던 2개 문서에 집중(상류 조판 개선 반영).
- 10.7% 문서(중소기업 취업 감면 신청서류) side-by-side 판정: **0.8.1이 더
  올바른 공식 서식 레이아웃** — 표 셀 비율·헤더 폭·자간이 원본 서식에
  가깝게 교정됨(잘림·겹침·깨진 글리프 없음, 양쪽 내용 동일).
- 결론: **시각 회귀 통과**. 0.8.1 범프는 렌더 품질을 해치지 않으며 일부
  문서에서 개선된다.

아티팩트(비교 PNG)는 로컬 `/tmp/visreg/`에서 확인.
